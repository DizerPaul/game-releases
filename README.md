# game-releases

Файлы для лаунчера игры Game (DizerGames). Сайт: https://launcher.dizermoney.ru/

- `channels/` — подписанные указатели на текущие версии (stable, beta)
- `launcher/` — информация о последней версии лаунчера
- `news/` — лента новостей из Telegram-канала
- `publisher/blobs.json` — служебный индекс утилиты публикации
- Releases — файлы игры (`game-<версия>`) и лаунчера (`launcher-<версия>`)

Файлы в этом репозитории создаются автоматически утилитой Publisher и workflow новостей. Вручную их не правьте.
